# 🌱 Instituto Sementes do Amanhã

Plataforma web desenvolvida para ONGs gerenciarem projetos, voluntários e doações.

## 🚀 Tecnologias
HTML5, CSS3, JavaScript (SPA Vanilla), GitHub Pages

## ♿ Acessibilidade
Conformidade com WCAG 2.1 AA, modo escuro e navegação por teclado.

## 📦 Estrutura
- /assets/css
- /assets/js
- /assets/img
- index.html

## 🔧 Como executar
Abra `index.html` diretamente no navegador.
